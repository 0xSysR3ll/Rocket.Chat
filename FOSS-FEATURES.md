# Rocket.Chat FOSS Version - Feature Guide

This document explains what features are available in the Free and Open Source Software (FOSS) version of Rocket.Chat and what requires a premium license.

## Available in FOSS Version

The FOSS version includes all the essential chat functionality you need for team communication. You get real-time messaging with instant delivery, file sharing and attachments, message threading for organized conversations, and comprehensive message search capabilities. Users can edit and delete messages, use mentions (@username), channel mentions (@channel, @here), and format messages with markdown. Message pinning and starring help organize important content.

### User Management

User management is fully functional with registration and authentication, customizable user profiles and avatars, and status indicators (online, away, busy, invisible). The system includes standard user roles (admin, moderator, user) with appropriate permission management. Users can block and mute others, and the system tracks user presence and activity.

### Room Management

Room management covers public and private channels, direct messages, room creation and management, descriptions and topics, member management, archiving capabilities, and search and discovery features. You can create the organizational structure that fits your team's needs.

### Security & Permissions

Security features include basic role-based permissions with the standard roles, permission management for those roles, two-factor authentication (2FA), session management, and password policies. This provides a solid security foundation for most use cases.

### Integrations

Integration capabilities include webhooks for incoming and outgoing data, full REST API access for custom integrations, basic OAuth integration for authentication, custom slash commands for automation, and a basic bot framework for extending functionality.

### Administration

Administrative tools include user and room management interfaces, comprehensive system settings configuration, log viewing capabilities, basic statistics, and backup and restore functionality to protect your data.

### Mobile & Desktop

Full mobile and desktop support includes native mobile apps for iOS and Android, desktop applications for Windows, macOS, and Linux, a responsive web interface, and push notifications to keep users connected.

### Data & Storage

Data management uses MongoDB for reliable storage, supports file uploads with proper storage, maintains complete message history, and provides user data export capabilities for compliance and migration needs.

## Premium Features (Require License)

> [!CAUTION]
> The following features require a Rocket.Chat Enterprise license and are not available in the FOSS version.

### Advanced Roles & Permissions

Custom roles for creating specific permission sets are a premium feature, along with advanced permission granularity and role-based room access control. These features are designed for organizations with complex permission requirements.

### Enterprise Authentication

Enterprise authentication includes SAML SSO, advanced OAuth configurations, comprehensive LDAP/Active Directory integration, and multi-factor authentication (MFA) for enhanced security in enterprise environments.

### Advanced Livechat

Livechat enterprise features include advanced routing and queuing systems, SLA management for customer service, and sophisticated visitor tracking for comprehensive customer support capabilities.

### Analytics & Reporting

Analytics features include an engagement dashboard, advanced analytics for detailed insights, custom reporting capabilities, and comprehensive usage statistics for organizational planning and optimization.

### Video & Voice

Video and voice capabilities include built-in video conferencing, voice calls, screen sharing functionality, and recording capabilities for meetings and presentations.

### Security & Compliance

Advanced security features include comprehensive auditing, compliance reporting for regulatory requirements, data retention policies, and advanced security features for enterprise-grade protection.

### Cloud & Scalability

Cloud features include managed Rocket.Chat hosting, scalability features for growing organizations, high availability configurations, and load balancing for optimal performance.

### Support

Enterprise support includes priority support channels, professional services for implementation and customization, and dedicated assistance for enterprise customers.

## How to Use This FOSS Version

> [!TIP]
> The FOSS version is perfect for basic chat needs, small to medium teams, self-hosting enthusiasts, and development/testing purposes.

This FOSS version provides all the essential chat functionality you need for team communication. It's perfect for organizations that need reliable chat without enterprise features, ideal for those who want to maintain control over their data and infrastructure, and great for testing, development, and learning purposes.

## When You Need Premium Features

> [!NOTE]
> Consider upgrading to Rocket.Chat Enterprise if you need enterprise-grade features.

Consider upgrading to Rocket.Chat Enterprise if you need custom roles for complex permission structures, enterprise SSO integration, advanced analytics and reporting, video conferencing, enterprise support, or cloud hosting services.
